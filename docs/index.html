MangosWatch

A FOSS Android tool to monitor network traffic and uncover Big Tech data collection.

View on GitHub

Overview

MangosWatch is designed to raise awareness about privacy and data sharing on Android phones. It monitors device network traffic, revealing which endpoints owned by Big Tech and major data collectors are contacted by installed apps and services, and classifies these connections against a curated taxonomy.

Core Features

  • Local VPN Interception: Hijacks device network traffic safely on-device without leaking data externally.
  • Deep Protocol & Handshake Parsing: Inspects TLS and QUIC handshakes alongside DNS queries to identify destination hosts.
  • Curated Endpoint Taxonomy: Matches IP addresses and endpoints against comprehensive taxonomies covering Amazon, Apple, Google, Meta, Microsoft, Netflix, Nvidia, OpenAI, Xiaomi, X/Twitter, and more.
  • Modern Android Tech Stack: Built entirely in Kotlin and Jetpack Compose with Koin dependency injection and the native hev-socks5-tunnel proxy.

Architecture & How It Works

MangosWatch operates locally via a background VPN service (VpnTrafficManager) that splits and inspects network streams:

  • VPN Capture: Intercepts raw network packets at the VpnService layer.
  • SOCKS5 Proxy Relay: Routes internet-bound traffic through the bundled native hev-socks5-tunnel library.
  • Traffic Analysis: The TrafficAnalyzer and StreamTrafficProcessor parse packets in transit.
  • Taxonomy Mapping: Resolves UIDs and app info (UidResolver, AppInfoResolver) and categorizes endpoints against curated asset lists.

Data Assets & Taxonomy

In the spirit of complete transparency, all classification data, IP range lists, and taxonomy definitions used by MangosWatch are fully open and publicly inspectable. The app dynamically syncs these definitions from the docs/data repository directory via GitHub Pages.

Note on Assets: If you notice any inaccuracies, missing endpoints, or misclassifications, corrections and pull requests are warmly welcomed!

Privacy Statement

MangosWatch never reads or logs encrypted payload contents. Classification is strictly based on destination endpoints, known IP ranges, and publicly documented company services. Your privacy remains fully protected.
